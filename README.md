## ◈ THE TRANSMISSION

**MERIDIAN** is an atmospheric, cinematic web experience built around the mystery of a distant frontier.

Imagine an endless desert, monumental structures emerging from the haze, a mysterious gateway standing beyond the horizon, and a world that reveals itself as you explore.

This project brings that atmosphere into the browser through immersive visual design, 3D environments, carefully composed lighting, and interactive storytelling.

It isn't just about displaying a scene.

**It's about making the browser feel like another world.**

## ◈ ENGINEERING THE EXPERIENCE

A compelling 3D experience requires more than adding a model to a webpage.

The design process considers:

- **Composition:** guiding attention through scale, silhouettes, and visual contrast.
- **Lighting:** creating depth and atmosphere through carefully balanced illumination.
- **Motion:** using animation to reinforce the environment rather than distract from it.
- **Interaction:** making user input feel connected to the world.
- **Performance:** managing scene complexity, rendering costs, and asset loading.
- **Responsive design:** adapting the interface to different screen sizes and input methods.

The goal is to balance visual ambition with a reliable, usable web experience.

## ◈ RUN THE EXPERIENCE LOCALLY

Want to explore the project on your own machine?

### Prerequisites

- Node.js — use a version compatible with the project.
- npm, or the package manager indicated by the repository lockfile.
- Git.

### 01 / Clone the repository

```bash
git clone https://github.com/adarshmuchatte-lang/meridian-3d-experience.git
cd meridian-3d-experience
```

### 02 / Locate the application

If the application files are inside a nested directory, enter that directory before installing dependencies:

```bash
cd meridian-3d-experience
```

Run this command only if that nested directory exists in your cloned repository. Otherwise, remain at the repository root.

### 03 / Install dependencies

```bash
npm install
```

### 04 / Start the development server

```bash
npm run dev
```

Open the local URL printed by the development server in your browser.

> **Important:** The commands above assume an npm-based Vite project. Check `package.json` and the repository's directory structure if the available scripts or package manager differ.
